Brainbox Web SDK v2.1 examples

Run node examples/mock-server.js and open one of:

  • floating.html - launcher + floating window (can dock to a sidebar)
  • sidebar.html - docked sidebar that pushes the page
  • inline.html - inline panel in a container, plus a floating widget on the same page
  • page.html - full-page layout with conversation list
  • v1-compat.html - old BrainboxWebSDK / BrainboxWebWidget API

Mock keywords: code, table, slow, fail, invalid, auth, nostream (stream endpoint answers 404, so the SDK falls back to /api/chat). Append ?theme=dark or ?theme=auto to any example.
